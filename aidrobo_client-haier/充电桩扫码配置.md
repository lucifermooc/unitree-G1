# 充电桩配置 WebSocket 接口文档

节点名：`set_pile_node`  
服务消息类型：`aid_robot_msgs/srv/SetString`

---

## 1. 设置充电桩 ID

**Service**：`/set_pile_id`

**调用**

```json
{
  "op": "call_service",
  "service": "/set_pile_id",
  "type": "aid_robot_msgs/srv/SetString",
  "args": {
    "data": "8"
  },
  "id": "<optional_string>"
}
```

> `data` 为十进制整数字符串，范围 `[0, 255]`

**响应**

```json
{
  "op": "service_response",
  "service": "/set_pile_id",
  "values": {
    "success": true,
    "message": "set id success"
  },
  "id": "<optional_string>"
}
```

**失败响应示例**

```json
{
  "op": "service_response",
  "service": "/set_pile_id",
  "values": {
    "success": false,
    "message": "Retrieval timed out"
  },
  "id": "<optional_string>"
}
```

---

## 2. 查询充电桩 ID

**Service**：`/get_pile_id`

**调用**

```json
{
  "op": "call_service",
  "service": "/get_pile_id",
  "type": "aid_robot_msgs/srv/SetString",
  "args": {
    "data": ""
  },
  "id": "<optional_string>"
}
```

> `data` 字段忽略，传空字符串即可

**响应**

```json
{
  "op": "service_response",
  "service": "/get_pile_id",
  "values": {
    "success": true,
    "message": "充电桩 ID: 8"
  },
  "id": "<optional_string>"
}
```

**失败响应示例**

```json
{
  "op": "service_response",
  "service": "/get_pile_id",
  "values": {
    "success": false,
    "message": "Retrieval timed out, please check if an ID is set."
  },
  "id": "<optional_string>"
}
```

---

## 3. 设置 433 通信信道

**Service**：`/set_pile_channel`

**调用**

```json
{
  "op": "call_service",
  "service": "/set_pile_channel",
  "type": "aid_robot_msgs/srv/SetString",
  "args": {
    "data": "40"
  },
  "id": "<optional_string>"
}
```

> `data` 为十进制整数字符串，范围 `[0, 80]`

**响应**

```json
{
  "op": "service_response",
  "service": "/set_pile_channel",
  "values": {
    "success": true,
    "message": "433 通道设置成功，通道号: 40"
  },
  "id": "<optional_string>"
}
```

**失败响应示例**

```json
{
  "op": "service_response",
  "service": "/set_pile_channel",
  "values": {
    "success": false,
    "message": "Channel setup failed."
  },
  "id": "<optional_string>"
}
```

---

## 错误响应汇总

| message | 原因 |
|---------|------|
| `"Retrieval timed out"` | 2 秒内未收到充电桩 CAN 回复 |
| `"Channel setup failed."` | 充电桩返回失败（CAN data[0]=0） |
| `"请输入有效十进制整数"` | `data` 不是合法整数，或超出范围 |
| `"请输入0~80之间的有效十进制整数"` | 信道号超出 `[0, 80]` |
