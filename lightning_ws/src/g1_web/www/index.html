地图列表

"使用"会把它设为当前地图并切换到定位模式（/set_current_map_id → /mode_set localization）。

    建图

    开始建图：从空白开始建一张新地图（G1D 会清空机器人上的实时地图，清空前自动备份；要点两次确认）。
    继续建图：在当前使用的地图上接着建（/mode_set continue_mapping；G1D 支持，G1 后端暂不支持）。
    建图时地图实时显示在左边（/map_base64）。

    点位

    在地图空地上按住鼠标、朝机器人到达后要面对的方向拖一下再松开新建点位；点选圆点可编辑，拖动圆点可移动。

    新点位

      语义地图

      说一句话，找到最相关的点位（名称 + 描述）。点位改动后会自动重建。

      调试记录

      所有来源（网页、服务调用、ASR 话题）的每一次请求。原文按收到的样子显示，看不见的字符用 黄底 标出来：原文就不对是发送方的问题；原文没问题但得分低或匹配错，是点位描述或阈值的问题。
